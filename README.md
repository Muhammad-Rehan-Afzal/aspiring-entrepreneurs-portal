An Interactive Web Portal for Aspiring Entrepreneurs

Final Year Project (BS Software Engineering): A centralized web application designed to guide aspiring entrepreneurs from ideation to execution through curated business resources, mentor/agent discovery, discussion forums, and role-based management.

Key Features by Role

1.	End-User
•	Sign-up and sign-in authentication
•	Search business categories and browse business mentors/entrepreneurs with full details and profiles
•	Explore business ideas, business frameworks, market research, opportunities, startup plans, partnership details, business templates, and financial support resources
•	Submit feedback to agents

2.	Entrepreneur / Agent
•	Submit registration details for admin approval
•	Sign in after approval to publish domain-specific resources (business ideas, business templates, opportunities, etc.)
•	Participate in discussion forums, private messaging, and share relevant contact details

3.	Admin
•	Secure admin login
•	Review agent profiles and approve or reject registrations (including credential provisioning)
•	Provide feedback to agents
•	Manage platform content (upload, edit, and delete content, tutorials, and events)

Tech Stack
•	Frontend: HTML, CSS, JavaScript, Bootstrap
•	Backend: PHP
•	Database: MySQL (SQL backup in `DB/` folder)
